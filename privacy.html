Política de Privacidade — Hermes Monolite

Última atualização: 27 de setembro de 2026

1. Responsável

Este aplicativo é mantido por Douglas Dalton Gehlen para uso interno e pessoal. Contato: douglasmonolite@gmail.com.

2. Dados acessados

O aplicativo acessa, mediante autorização via OAuth, somente a conta Google do próprio responsável, incluindo arquivos do Google Drive e os demais serviços Google expressamente autorizados na tela de consentimento.

3. Finalidade

Os dados são usados exclusivamente para criar, salvar e organizar arquivos relacionados a obras (fotos, vídeos, relatórios e resumos), a pedido do próprio usuário.

4. Compartilhamento

Os dados não são vendidos, cedidos ou compartilhados com terceiros para fins de publicidade ou qualquer outra finalidade. O uso de dados obtidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Armazenamento e segurança

Os tokens de acesso ficam armazenados apenas no servidor privado do responsável. Os arquivos permanecem na conta Google do próprio usuário.

6. Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

7. Alterações

Esta política pode ser atualizada; a data da última revisão aparece no topo desta página.
